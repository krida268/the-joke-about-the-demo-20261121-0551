# The Joke About the Demo

A one-line joke about working alongside an AI coding agent — set during a live demo, where the agent finishes the feature, fixes an unreported bug, and then turns the tables by asking the audience to rate the human's prompting.

## Run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the joke to `out/entry.txt` (UTF-8, one line, 1–280 characters). Deterministic, no network, no wall clock — Node 22 stdlib only.
